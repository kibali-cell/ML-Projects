# Machine Learning Projects Portfolio

A collection of end-to-end machine learning projects covering predictive analytics, NLP, computer vision, and time series forecasting — built to demonstrate practical, applied skills in data preprocessing, model development, evaluation, and deployment.

**Portfolio site:** [jonasml.netlify.app](https://jonasml.netlify.app/)

---

## Skills Demonstrated

| Area | Techniques / Tools |
|---|---|
| Supervised Learning | Regression, Classification, Random Forest, XGBoost, SVM |
| Deep Learning | Neural Networks, CNNs, Object Detection (SSD) |
| NLP | Text classification, spam detection (multilingual — Swahili) |
| Recommendation Systems | Collaborative filtering |
| Data Engineering | Feature engineering, preprocessing pipelines, EDA |
| Tooling | Python, Scikit-learn, TensorFlow/PyTorch, Pandas, NumPy, Jupyter |

## Getting Started

```bash
git clone https://github.com/kibali-cell/ML-Projects.git
cd ML-Projects
pip install numpy pandas scikit-learn tensorflow matplotlib seaborn jupyter nltk
jupyter notebook
```

Each notebook is self-contained: open it, run the cells in order, and follow the inline explanations.
